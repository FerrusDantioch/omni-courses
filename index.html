        Installation sur Android

        Dans Chrome, ouvre le menu ⋮ puis « Ajouter à l'écran d'accueil » ou « Installer l'application ».

        Si Chrome indique « Cette appli est déjà installée » alors qu'elle ne l'est pas, c'est une limite de Chrome quand une autre application de ce site est déjà installée. Utilise un autre navigateur (Brave, par exemple), ou choisis « Créer un raccourci ».
